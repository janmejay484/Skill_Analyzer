A **MERN + AI powered platform** that helps developers analyze their portfolio, identify skill gaps, and get personalized career insights.  
Users can create profiles, upload resumes, add projects & skills, and run an **AI analysis** for career guidance.  

---

## ✨ Features  

- 👤 **User Authentication** (JWT-based login & signup)  
- 📊 **Dashboard** with profile info, skills, and projects  
- 📂 **Resume Upload & Storage** for AI analysis  
- 🤖 **AI-Powered Skill Gap Analysis** using OpenAI  
- 🔗 Save **GitHub & LinkedIn links**  
- 💾 **MongoDB Atlas** for persistent data storage  

---

## 🚀 Tech Stack  

| Layer        | Technology |
|--------------|------------|
| **Frontend** | React (Vite), Modular CSS |
| **Backend**  | Node.js, Express.js |
| **Database** | MongoDB Atlas |
| **AI**       | OpenAI API |
| **Auth**     | JWT (JSON Web Token) |

## 🛠️ Installation & Setup  

Clone the repo:  


git clone https://github.com/janmejay484/SkillSync.git
cd SkillSync

🔧 Backend Setup
cd server
npm install

🔧 Create a .env file inside server/:

MONGO_URI=your-mongodb-uri
JWT_SECRET=your-secret-key
OPENAI_API_KEY=your-openai-api-key
PORT=5000

🔧Run server:
npm start

🎨 Frontend Setup
cd client
npm install
npm run dev


Visit 👉 http://localhost:5173

🎯 User Flow

Register/Login using email & password
Go to dashboard → Start Analysis
Fill portfolio form with skills, projects, resume, GitHub/LinkedIn links
AI analyzes your profile & suggests skill improvements
Dashboard shows structured profile + edit/delete options
